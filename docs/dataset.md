# Dataset

## Overview

This project uses real-world robot demonstrations collected through a leader-follower teleoperation system.

The demonstrations were recorded using the LeRobot-record framework and used to train an Action Chunking with Transformers (ACT) policy for robot manipulation.


## Hardware Setup

The data collection system consists of:

### Leader Arm

- Robot: SO101 robotic arm
- Role: Human-operated demonstration device

The operator manually controls the SO101 arm to provide manipulation demonstrations.


### Follower Arm

- Robot: Piper robotic arm
- Role: Robot execution device

The Piper arm follows the demonstrated trajectories and records the corresponding robot states and actions.


The complete data collection pipeline:
Human Demonstration
    ↓
SO101 Leader Arm
    ↓
LeRobot-record
    ↓
Piper Robot Execution
    ↓
Robot Demonstration Dataset



## Dataset Statistics

The ACT training dataset contains:

| Item | Value |
|---|---|
| Episodes | 55 |
| Total Frames | 13,311 |
| Frequency | 15 FPS |
| Episode Duration | ~30 seconds |
| Robot | Piper |
| Collection Method | LeRobot-record |


## Data Modalities

Each demonstration contains multiple synchronized modalities.


### Visual Observation

RGB camera observations:

- Camera images from robot workspace
- Used as visual input for ACT policy


### Robot State

Recorded robot states:

- Joint positions
- Robot configuration information


### Actions

Robot actions:

- Target robot commands
- Demonstration trajectories generated by teleoperation


## Dataset Structure

The dataset follows the LeRobot dataset format. There is a dataset file in this project except the videos.



## Data Collection Process

The collection process:

1. Human operator controls the SO101 leader arm.
2. Piper executes the corresponding manipulation trajectory.
3. LeRobot-record records:
   - camera observations
   - robot states
   - action trajectories
4. Recorded demonstrations are converted into a LeRobot dataset.
5. The dataset is used for ACT behavior cloning training.


## Dataset Usage

The dataset is used for supervised imitation learning.

Training objective:
Robot Observation
    ↓
ACT Policy
    ↓
Predicted Action Chunk
    ↓
Robot Execution



## Notes

The dataset was collected in a real robot environment.

Because ACT is a behavior cloning method, the quality and diversity of demonstrations directly affect policy performance.
